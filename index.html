Before you continue

This tool combines multiple G-code files into a single program and automatically inserts tool-change commands, unit/positioning resets, and — if enabled — rewrites travel moves. It has only been tested with gsender on an Altmill 4x4 MK2 running grblHAL. Behavior with other senders, controllers, post-processors, or machines has not been verified and may differ in ways that could cause unexpected or unsafe motion.

Before running any file this tool produces on real hardware, you should:

  • Read through the entire generated file yourself, paying close attention to each tool change, feed rate, and retract height.
  • Confirm the tool numbers match what's actually loaded in your machine's tool holders.
  • If you enable the experimental "convert to fast travel moves" option, manually review every move it reclassified as a rapid before trusting it.
  • Run a dry run, air cut, or single-block step-through first, and keep a hand near the e-stop for the first real pass.

This tool is provided as-is, with no warranty that it produces correct or safe G-code for your specific setup. Verifying every file before it touches your machine is entirely your responsibility.

    This tool has only been tested with gsender on an Altmill 4x4 MK2 running grblHAL. Verify the combined file carefully — ideally with an air-cut or a single-step-through — before running it on your machine.

    How it works

    1. Drag your G-code files onto the box on the left, or click it to pick files. Each file should already contain the correct tool number for its own operation (whatever your CAM post-processor put there) — that's what this tool reads, it doesn't assign tool numbers itself.
    2. Drag the entries in the list to set the order the files should run in.
    3. Click Process. Each file's existing tool-select line (e.g. T2) gets M6 appended to it so grblHAL actually performs the change, and the files are stitched into one continuous program with a single end-of-program block at the very end instead of one per file.
    4. The result appears in the Result tab as editable text — check it over, then click Save to download it as a .gcode file.

    Your file list and option settings are remembered in this browser between visits, so you don't need to re-upload or re-configure every time.

    What the options do

    Strip duplicate headers

    Post-processors write a header at the top of every file — program name, tool note, units/plane setup, and an initial retract. That's only correct once. With this on, only the first file keeps its header; every later file starts at its own operation comment instead of repeating the whole setup.

    Remove extra comments

    Strips descriptive, non-executable comments (tool notes, operation names, CAM disclaimers, etc.) from each file's body to keep the combined file smaller and easier to read. This never removes the file-separator comments this tool itself adds for traceability.

    Convert to fast travel moves (experimental)

    Fusion 360's Personal Use license silently downgrades non-cutting travel moves from a true rapid (G0) to a fed move (G1) with no new feedrate — so retracts and repositions crawl at your last cutting feedrate instead of moving quickly. This option tries to detect and restore those moves back to G0. It uses a conservative rule (only Z-only moves that retract upward, or X/Y-only moves made right after such a retract) and leaves every plunge and arc untouched — but it's a heuristic based on move geometry, not a true understanding of your toolpath, so it's marked experimental and defaults off. Review the converted moves before running the file.

    Insert after tool change

    G-code emitted right after every tool change, one command per line. Defaults to G20 / G90 (inches, absolute positioning) because grblHAL always reports machine position in millimeters during the tool-change pause — if that gets fed back into a move while units have drifted, the target can be off by 25.4x and trip a soft-limit alarm. Change this if your machine uses different units or needs other commands reasserted after a change.
